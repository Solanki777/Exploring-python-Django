### 8. For migrations to keep save changes in  models.py

```bash
python manage.py makemigrations
```

then use to final to done changes in the database

```bash
python manage.py migrate
```


for each change in database(models.py) the migration file is generated by Django like 0001,0002,0003 ... These shows us that how the changes are done from one to other state and all changes are depended on each other if any migration file is deleted then the whole project will crashes . You can find the changes in dependencies in migration file
