
```bash
python manage.py migrate
```


for each change in database(models.py) the migration file is generated by Django like 0001,0002,0003 ... These shows us that how the changes are done from one to other state and all changes are depended on each other if any migration file is deleted then the whole project will crashes . You can find the changes in dependencies in migration file

### 10. To show the image file configuration:

In your project's urls.py:

```bash
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    # your urls
]

if settings.DEBUG:
    urlpatterns += static(
        settings.MEDIA_URL,
        document_root=settings.MEDIA_ROOT
    )

```

in your project settings.py at last

```bash 
STATIC_URL = 'static/'

MEDIA_URL = '/media/'
MEDIA_ROOT = BASE_DIR / 'media'
```

use .url after file name like this
